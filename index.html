I'm a Cloud & DevOps Engineer based in Dhaka. I work hands-on with containers, orchestration and CI/CD. My daily work covers Linux administration, Docker, Kubernetes, AWS, and observability with Prometheus & Grafana.

I care most about DevSecOps. Security should be built into the pipeline from the start, not added at the end. That means container security, secret management, WAF policies and hardened infrastructure, all automated.

Outside work I run a homelab: a 3-node kubeadm cluster on Vagrant VMs with Cilium, Argo CD and a full Prometheus/Loki stack. I use it to test new ideas before they go to production.

I have a CS degree from MIST, a thesis on spyware detection, and a background in CTF competitions. So I look at infrastructure the way an attacker would, and I build it so it scales and stays reliable.

Cloudly: a full GitOps platform on a self-built Kubernetes cluster

A React + Node.js app with PostgreSQL and Redis, running on my own 3-node kubeadm cluster (Vagrant VMs, Kubernetes v1.34, Cilium CNI). Covers the whole delivery lifecycle, from GitHub Actions CI to Argo CD GitOps, with Kustomize overlays for dev, preprod and release.

  • Images tagged branch + commit SHA, and rollback is just a git revert. CI never gets cluster access: Argo CD pulls changes from inside the cluster.
  • Observability: kube-prometheus-stack with a custom Grafana dashboard (RPS, error rate, p95), 5 alert rules, and Fluent Bit → Loki for logs.
  • Hardened: internal ClusterIP-only services, non-root multi-stage images, liveness/readiness probes, and read/write DB routing.

Go microservices (student / teacher / employee) with a React frontend and MongoDB, deployed to Kubernetes through GitLab CI, Jenkins and a separate GitOps manifests repo.
